\subsection{Recomputing ESI from logged numbers}
Using $|\Active|=12$, $M_{\Active}=1.0202161853$:
\begin{align}
\hat{M}_{\Active}
&= 1 - \exp\left(-\frac{1.0202161853}{12}\right) \\
&= 1 - \exp(-0.0850180154) \\
&\approx 0.0815042629.
\end{align}
Because raw coverage and connectivity are both 1.0, smoothed values are also 1.0.
Therefore:
\begin{align}
\ESIprod &= 0.0815042629, \\
\ESIgeom &= (0.0815042629)^{1/3} \approx 0.4335708821.
\end{align}
These match logged values exactly (up to floating-point precision).
