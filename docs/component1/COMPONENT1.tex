\begin{abstract}
This document is a code-aligned technical specification for \texttt{src/component1/} and
\texttt{scripts/run\_component1\_pv\_esm.py} in the Fact-or-Fiction repository.

and (ii) exact implementation traceability for development, debugging, and reproducibility.
The document is modularized into multiple \LaTeX{} files to keep each concept focused,
including mathematical definitions, parameter defaults, edge-case behavior,
and real examples extracted from actual Component 1 outputs.
